## Featured Project

### Firewall Defender — Scratch

My first CS50x project is an arcade-style game where the player acts as a firewall defender, stopping malicious packets from reaching a server.

**Objective:** Block 10 malicious packets to secure the server and win.

**Concepts practiced:**
- Events and scripts
- Loops and conditionals
- Variables and game state
- Custom blocks with inputs
- Collision detection and game logic
- Debugging and iterative development
